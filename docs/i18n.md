# Interface language (ES | EN)

- **Default:** Spanish (Colombia), because the dashboard is presented to a Colombian audience. The **ES | EN** switch in the top bar changes it, and the choice is stored in `localStorage` (`lang`).
- **Dictionaries:**
  - `src/i18n/en.ts` is the source shape; `src/i18n/es.ts` is typed as the same `Messages`, so a missing key or a changed function signature fails the typecheck.
  - Components read copy with `useT()` (e.g. `t.flow.panel.peakHour`). Parametrised text is a function (e.g. `t.calendar.tipCore(n)`).
- **Formatting** (`src/lib/format.ts`):
  - The provider sets the locale (`en-US` or `es-CO`) before rendering. Spanish gives 683.405, 64,9 % (with a non-breaking space) and dom 22 dic 2024.
  - Observable Plot charts redraw on language change (`PlotFigure` adds the language to its dependencies).
- **Data:**
  - holiday names are published in both languages (`holiday`, `holiday_es` in `spikes.json` and `daily_totals.json`);
  - spike drivers are keys (`driver`), translated in the UI (`src/calendar/labels.ts`).
- **Demo:** `t.tour` holds the ten step titles and narrations as functions of the facts computed from the data, so the tour can switch language mid-run.
- **Vocabulary:**

  | English | Spanish |
  |---|---|
  | boardings | abordajes (not pasajeros) |
  | weekday | día hábil |
  | Sundays & holidays | domingos y festivos |
  | peak hour | hora pico |
  | like-for-like | comparación equivalente |
  | hypothesis | hipótesis |
  | long weekend | puente festivo |
- **Checks:**
  - the functional browser checks pin English through `localStorage`;
  - `npm run ui:shots` runs in Spanish by default (pass `en` as the 3rd argument for English);
  - `a11y-check` scans both languages.
